# FoodDelivery — система замовлення та доставки їжі

Наскрізний проєкт з дисципліни «WEB-програмування».

## 🛠 Стек технологій
* **Frontend:** HTML5, CSS3 (SASS), Bootstrap 5, JavaScript (ES2022), React, TypeScript
* **Backend:** Node.js, Express
* **База даних:** MySQL
