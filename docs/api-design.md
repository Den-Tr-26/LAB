# REST API проєкту FoodDelivery
Базова адреса: `http://localhost:3000/api`

| # | Ресурс | Метод | Призначення | Успіх | Помилки |
|---|--------|-------|-------------|-------|---------|
| 1 | `/restaurants` | GET | перелік ресторанів | 200 | 500 |
| 2 | `/restaurants/:id` | GET | інформація про ресторан | 200 | 404 |
| 3 | `/restaurants/:id/dishes` | GET | меню страв ресторану | 200 | 404 |
| 4 | `/dishes` | GET | перелік страв із фільтрацією | 200 | 400 |
| 5 | `/dishes/:id` | GET | картка страви | 200 | 404 |
| 6 | `/dishes` | POST | створення страви (для ресторану) | 201 | 422 |
| 7 | `/dishes/:id` | PUT | оновлення страви | 200 | 404, 422 |
| 8 | `/dishes/:id` | DELETE | видалення страви | 204 | 404 |
| 9 | `/orders` | POST | оформлення замовлення | 201 | 422 |
| 10| `/orders/:id` | GET | перегляд статусу замовлення | 200 | 404 |

## Параметри GET /dishes
| Параметр | Тип | Приклад | Опис |
|----------|-----|---------|------|
| `restaurant` | int | `?restaurant=2` | фільтр за рестораном |
| `category` | string | `?category=pizza` | фільтр за категорією страв |
| `maxPrice` | int | `?maxPrice=300` | верхня межа ціни |
| `q` | string | `?q=маргарита` | пошук за назвою страви |
| `sort` | enum | `?sort=price_asc` | сортування |
| `page` | int | `?page=1` | номер сторінки |
