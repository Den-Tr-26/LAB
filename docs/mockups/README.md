# Маккети інтерфейсу (Mockups) — FoodDelivery

## Огляд екранів

1. **Головна сторінка (`/`)**
   * Шапка з логотипом, адресою доставки та пошуком.
   * Список ресторанів у вигляді карток із рейтингом та часом доставки.
   * Блок із популярними стравами.

2. **Меню ресторану (`/restaurant/:id`)**
   * Інформація про заведение (лого, назва, категорії).
   * Каталог страв, розбитий за категоріями (суші, піца, напої).
   * Кнопка «Додати до кошика» біля кожної страви.

3. **Кошик та замовлення (`/cart`, `/order`)**
   * Список обраних страв із можливістю зміни кількості.
   * Підрахунок загальної суми замовлення.
   * Форма введення даних покупця (ім'я, телефон, адреса) з валідацією.
